# 批量文件 7Z 压缩 / 解密工具

这是一个基于 Python 和 Tkinter 开发的批量文件压缩与解密工具，专为 Windows 11 环境设计。

## 功能特点

- **双向模式**：支持批量压缩和批量解密。
- **层级保留**：严格保留原文件夹的目录结构。
- **批量处理**：自动递归处理所有子文件夹。
- **密码保护**：支持设置压缩密码（解密时必须提供）。
- **自定义输出**：支持自定义输出文件夹后缀。
- **进度反馈**：提供全局进度条、当前文件进度和实时日志。

## 运行要求

1. **Python 3.x**：确保已安装 Python。
2. **7z.exe**：
   - 工具会自动在当前目录下查找 `7z.exe`。
   - 如果当前目录没有，会尝试查找默认安装路径 `C:\Program Files\7-Zip\7z.exe`。
   - **注意**：本项目根目录下已包含 `7z.exe` 和 `7z.dll`，直接运行即可。

## 如何运行

直接运行 `main.py` 即可启动图形界面：

```bash
python main.py
```

## 文件结构

- `main.py`: GUI 入口程序。
- `core.py`: 核心业务逻辑（压缩/解密处理）。
- `utils.py`: 工具函数（路径查找等）。
- `test_runner.py`: 用于测试核心功能的脚本。

## 开发说明

- **GUI 框架**：使用 Python 内置的 `tkinter`。
- **核心引擎**：通过 `subprocess` 调用 `7z.exe` 进行文件操作。
- **多线程**：耗时操作在独立线程中运行，防止界面卡顿。
